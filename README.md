# MIT 8103 – Advanced Database Systems Portfolio

## Case Study: NorthEdge Assurance Ltd.

This repository contains my practical portfolio for the MIT 8103 Advanced Database Systems course.

The portfolio explores the design, implementation, querying, optimisation and management of an insurance database system.

## Portfolio Contents

1. Portfolio 1 – Database Design and Modelling
2. Portfolio 2 – Query Processing and Optimisation
3. Portfolio 3 – Transactions and Concurrency
4. Portfolio 4 – NoSQL and Advanced Data Models
5. Portfolio 5 – Distributed and Cloud Database Exercise
